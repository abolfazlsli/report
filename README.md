# سامانه کارنامه

سامانه مدیریت کلاس‌ها، ثبت نمره و کارنامه دانش‌آموزان با سه پنل **مدیر**، **معلم** و **دانش‌آموز**.

- **Backend:** FastAPI + SQLAlchemy 2 + PostgreSQL (احراز هویت JWT)
- **Frontend:** Next.js 15 (App Router) + Ant Design 6 + Recharts — راست‌چین، فونت وزیر، تقویم شمسی (dayjs + jalaliday)، حالت تاریک خودکار
  - Tailwind فقط برای چیدمان (بدون preflight) استفاده می‌شود؛ ظاهر کامپوننت‌ها از تم antd در `src/app/providers.tsx` می‌آید.
  - همه جدول‌ها جستجو، فیلتر ستونی و مرتب‌سازی دارند (helperها در `src/lib/table.tsx`).

## اجرا

پیش‌نیازها: Docker، Python 3.12، Node 20 یا بالاتر.

```bash
# 1) دیتابیس
docker compose up -d

# 2) بک‌اند  (http://localhost:8060  — مستندات API: /docs)
cd backend
python -m venv .venv
.venv\Scripts\activate            # در لینوکس/مک: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env            # در لینوکس/مک: cp
python -m app.seed                # ساخت جداول + مدیر + داده نمونه   (--bare = فقط مدیر)
uvicorn app.main:app --port 8060 --reload

# 3) فرانت‌اند  (http://localhost:3000)
cd frontend
npm install
copy .env.example .env.local
npm run dev
```

> پورت API عمداً 8060 است چون روی این سیستم ویندوز پورت 8000 در محدوده رزرو‌شده Hyper-V قرار دارد.
> برای تغییر، `NEXT_PUBLIC_API_URL` در `frontend/.env.local` را عوض کنید.

### حساب‌های نمونه (بعد از `app.seed`)

| نقش | نام کاربری | رمز |
|---|---|---|
| مدیر | `admin` | `admin123` |
| معلم علوم / ریاضی / فارسی | `teacher1` / `teacher2` / `teacher3` | `teacher123` |
| دانش‌آموز | `student1` … `student5` | `student123` |

داده نمونه: ۵ دانش‌آموز که سال 1404-1405 در «پایه اول - الف» بوده‌اند (۹ نمره در هر درس) و به «پایه دوم - الف» در دوره جاری 1405-1406 ارتقا یافته‌اند؛ بنابراین کارنامه‌شان سابقه دو دوره را نشان می‌دهد.

## مدل داده

```
AcademicYear (دوره) ─┐
Grade (پایه) ────────┼─> ClassRoom (کلاس) ─> ClassSubject (درس کلاس + معلم)
                     │        │                      │
User(student) ─ Enrollment ───┘                       │
                     └──────── Score (نمره) <─────────┘
```

- **Enrollment** = حضور یک دانش‌آموز در یک کلاس (در یک دوره). هر دانش‌آموز حداکثر یک ثبت‌نام «فعال» دارد (ایندکس یکتای جزئی در Postgres).
- **ارتقا**: ثبت‌نام قبلی با وضعیت `promoted` (یا `completed` برای فارغ‌التحصیلی) بسته می‌شود و ثبت‌نام جدید در کلاس مقصد باز می‌شود. نمرات به ثبت‌نام قبلی متصل می‌مانند، پس **سابقه تحصیلی هیچ‌وقت بازنویسی نمی‌شود**.
- **حفظ سوابق**: کلاس/پایه/دوره/درسی که سابقه دارد قابل حذف نیست؛ خروج دانش‌آموزی که نمره دارد او را `withdrawn` می‌کند؛ کاربری که سابقه نمره دارد باید غیرفعال شود، نه حذف.
- هر نمره معلمِ ثبت‌کننده‌اش را نگه می‌دارد، حتی اگر بعداً معلم درس عوض شود.

## نقش‌ها

| | مدیر | معلم | دانش‌آموز |
|---|---|---|---|
| تعریف دوره، پایه، درس، کلاس | ✓ | | |
| ساخت کاربر، افزودن معلم و دانش‌آموز به کلاس | ✓ | | |
| ارتقا / انتقال / فارغ‌التحصیلی | ✓ | | |
| ثبت، ویرایش و حذف نمره | | ✓ (فقط درس‌های خودش، فقط دانش‌آموزان فعال) | |
| مشاهده نمرات و کارنامه | همه | دانش‌آموزان کلاس‌های خودش | فقط خودش |

## ساختار پوشه‌ها

```
backend/app/
  models.py         مدل‌های دیتابیس
  schemas.py        ورودی/خروجی API
  services.py       ساخت کارنامه و برگه نمرات (مشترک بین نقش‌ها)
  routers/          auth, admin, teacher, student
  seed.py           داده اولیه
frontend/src/
  app/admin|teacher|student/   صفحات هر پنل
  app/providers.tsx            تم antd، راست‌چین، locale فارسی، حالت تاریک
  components/ReportCard.tsx    کارنامه + نمودارها
  components/ScoreSheet.tsx    برگه نمرات کلاس (ثبت گروهی نمره)
  components/charts.tsx        نمودار روند نمرات و معدل دوره‌ها
  lib/jalali.ts                DatePicker شمسی برای antd
  lib/table.tsx                فیلتر/جستجو/مرتب‌سازی مشترک جدول‌ها
  lib/                          کلاینت API، احراز هویت، فرمت تاریخ/عدد
```

## کارهای بعدی پیشنهادی

- مایگریشن با Alembic (فعلاً جداول هنگام اجرا با `create_all` ساخته می‌شوند)
- عوض کردن `SECRET_KEY` و رمزهای نمونه قبل از استقرار
- خروجی PDF/چاپ کارنامه، ورود گروهی دانش‌آموزان از اکسل
